<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → FastAPI (localhost) | Unauthenticated preview; trusted only because default bind is loopback |
| CLI --host/--url/--path → process | Operator-controlled; URL may embed credentials |
| MJPEG clients → encode loop | Multiple tabs increase CPU; keep-latest prevents memory spiral |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-03 | Information Disclosure | sentry serve host bind | mitigate | Default host 127.0.0.1; help + README warn on 0.0.0.0; tests assert default (Task 3) |
| T-2-01 | Tampering | --path / --url | mitigate | No shell invocation; OpenCV only; docs warn RTSP credentials in argv (Task 3 + camera-sources.md) |
| T-2-02 | Denial of Service | MJPEG subscribers | mitigate | Keep-latest bus (02-02); ~30 FPS UI sleep in generator; single-slot frames (Task 1) |
| T-2-04 | Integrity | Preview status | mitigate | /api/status + HTML pill leave green only when streaming; reconnecting/error visible (Tasks 1–2) |
| T-2-SC | Tampering | fastapi/uvicorn/httpx | mitigate | RESEARCH Approved packages; uv.lock pins |
</threat_model>
