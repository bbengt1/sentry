## Locked decisions (do not re-litigate)

| Decision | Value |
|----------|-------|
| Overlay transport | Server-side OpenCV **COLORMAP_TURBO** alpha-blend on BGR before MJPEG encode (UI-SPEC preferred; Option A parity with detection) |
| Drawing library | OpenCV only — no client-side depth decode |
| Wire depth | `DepthPayload` metadata + stats only — **never** full HxW float in JSON |
| Snapshot path | Extend `GET /api/snapshot` (not full `/v1` robot stream — Phase 5) |
| 404 policy | 404 only when **neither** detection nor depth product exists; depth-only or det-only → 200 with completeness flags |
| Single truth | MJPEG + snapshot + UI metrics all read PerceptionStore (no second model path) |
| Inference location | Still only DepthLoop thread — never in handlers |
| create_app | Inject store/workers; do **not** start threads (caller owns lifecycle) |
| Metric mode | Optional; default relative; when enabled kind=metric_estimated unit=m + clear labels; never conflate with relative |
| Depth config API | Thin GET/PATCH `/api/depth/config` with `depth_mode` enum (mirror detection conf) for DEPTH-04 labeling |
| Colormap alpha | Default **0.45** blend (RESEARCH discretion) |
| Empty depth | Skip blend; stream stays 200; status may show unavailable / error |
| Out of scope | Free-space overlays, stage enable matrix (Phase 6), side-by-side dual players, binary depth wire |
