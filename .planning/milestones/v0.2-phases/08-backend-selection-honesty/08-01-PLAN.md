| T-08-02 | Elevation of privilege | Loading arbitrary model file | mitigate | `ALLOWED_DETECTOR_STEMS` only; no remote URL fetch; no invent path |

| T-08-05 | Information disclosure | Artifact paths in logs | accept | Local operator tool; no PII; paths are model artifacts |
| T-08-SC | Tampering | Package installs | mitigate | No new packages this phase — no install tasks |
