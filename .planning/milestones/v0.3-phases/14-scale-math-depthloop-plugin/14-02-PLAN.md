| Decision | Value | Source |
|----------|-------|--------|
| Apply formula | map' = scale*map + offset (not inverse-depth) | RESEARCH lock #3 |
| Copy-on-write | New float32 array in apply_map; do not mutate worker buffer | RESEARCH lock #9 |
| Lock | Read applied scale/offset under CalibrationState lock in apply_map | RESEARCH lock #9 |
| Base kinds | Same apply for relative and metric_estimated; fingerprint depth_mode+model_id; no undo of metric prior | RESEARCH lock #6 |
| Promotion | Use Phase 13 `promote_kind_unit` — only applied+valid → metric_calibrated + m | Phase 13 |
| Module split | Fit in spatial/calibration.py (14-01); apply_map on control/calibration_state.py | RESEARCH lock #8 |
| DepthLoop path | worker.process → promote → apply_map → set_depth | ROADMAP / user brief |

| Constraints | Zero new deps; freeze DetectionLoop/FrameBus/ORT-TRT; synthetic tests; no wizard/YAML/free-space meters | RESEARCH lock #9 |
