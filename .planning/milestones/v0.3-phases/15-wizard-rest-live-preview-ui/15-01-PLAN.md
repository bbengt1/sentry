## Claude's discretion (chosen for this plan)

| Item | Choice |
|------|--------|
| Sample storage | Public add/get/clear on CalibrationState (field `_draft_samples` already exists) |
| Freeze pin | `app.state.calibration_freeze_pin` holding a copied DepthProduct-like snapshot — not on CalibrationState (keeps control plane FastAPI-free) |
| Sample-while-applied | HTTP 409 (not 422) |
| Compute default | `fit: "median"` → fit_scale_median; `fit: "affine"` → fit_affine_lstsq |
| DELETE samples | clear_draft_samples AND drop draft params (fit is stale). Recommended: `clear_draft()` for DELETE samples; freeze pin may remain |
| Cancel after apply | Leaves applied; drops leftover draft/pin |
| Height helper | Optional `known_height_to_distance_m` in spatial/calibration.py; if body has known_height_m + bbox and no known_meters, convert; if both, known_meters wins |
| Status when inactive | Include `calibration_active: false` and `calibration_sample_count` when state is injected; omit scale/method/camera_id unless applied |
| DepthLoop write | Handlers never set_depth; WIZ-04 proven by snapshot remaining relative after compute/apply until a loop tick |
| create_app default | `calibration_state=None` for backward compat |
