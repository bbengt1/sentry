- `DepthKind`: `relative` | `metric_estimated` | `metric_calibrated` (str Enum values exactly these strings)
- No field named `depth_m` anywhere on depth payload
- Relative must not set `unit="m"` (or any unit)
- `camera_id` required on Frame and PerceptionFrame from day one
- `extra="forbid"` on wire models
- Timestamps: `t_capture: float` as epoch seconds (document in module docstring); optional `t_ingest` / `t_publish` as float | None
- Profiles: exactly `desktop-gpu`, `jetson`, `cpu-fallback` via `RuntimeProfile` enum
- MODEL-01: `allow_cloud: false` default; no mandatory cloud
